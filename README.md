# Blastbound

An original browser-based rocket tank arena prototype.

## Requirements

- Node.js
- A modern web browser

## Run locally

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed in the terminal.

## Build for deployment

Run:

`npm run build`

Vite creates the production website inside the `dist` folder.

## Current features

- Original homepage and visual design
- Tank movement
- Mouse aiming
- Rocket firing
- Training bots
- Health and score
- Restart button

## Not implemented yet

- Online multiplayer
- User accounts
- Matchmaking
- Persistent scores
- Mobile touch controls
